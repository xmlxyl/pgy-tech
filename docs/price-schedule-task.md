# 划线价修改任务功能设计文档

## 1. 功能目标

商家通过 Excel 批量导入 SKU 和目标价格，创建一个划线价修改任务。任务创建后不再自动定时执行，由商家在任务列表中手动点击“修改价格”或“恢复价格”。

修改价格时，系统将商品变体设置为：

- `price = 目标价格`
- `compareAtPrice = 原价`

恢复价格时，系统将商品变体设置为：

- `price = 原价`
- `compareAtPrice = null`

## 2. 页面范围

### 2.1 任务列表

页面展示所有划线价修改任务，支持：

- 下载 Excel 模板。
- 新建任务。
- 查看详情。
- 手动执行修改价格。
- 手动执行恢复价格。

列表字段：

| 字段     | 说明                                                   |
| -------- | ------------------------------------------------------ |
| 任务名称 | 点击进入详情                                           |
| SKU 数量 | Excel 中有效 SKU 数                                    |
| 状态     | 待修改、修改中、已修改、恢复中、已恢复、部分失败、失败 |
| 结果     | 成功数 / 失败数                                        |
| 创建时间 | 北京时间展示                                           |
| 操作     | 详情、修改价格、恢复价格                               |

### 2.2 新建任务

表单字段：

| 字段       | 必填 | 说明                         |
| ---------- | ---- | ---------------------------- |
| 任务名称   | 是   | 便于商家识别任务             |
| Excel 文件 | 是   | 上传后自动解析并展示确认表格 |

Excel 上传后立即解析，不受任务名称等表单校验限制。确认创建时才校验任务名称和 Excel 解析结果。

### 2.3 详情页

详情页展示：

- 任务状态。
- Excel 文件名。
- SKU 总数、成功数、失败数。
- 创建时间。
- SKU 明细：SKU、原价、目标价格、修改状态、恢复状态、错误原因。

## 3. Excel 模板

模板字段：

| 字段         | 必填 | 说明                 |
| ------------ | ---- | -------------------- |
| SKU          | 是   | Shopify 商品变体 SKU |
| Target Price | 是   | 修改后的销售价格     |

校验规则：

- SKU 不能为空。
- Target Price 必须是大于等于 0 的数字。
- 同一个 Excel 内 SKU 不能重复。
- SKU 必须能在 Shopify 中唯一匹配到一个商品变体。
- Target Price 必须小于当前价格，才能生成划线价。

## 4. 状态设计

任务状态：

| 状态            | 说明                 |
| --------------- | -------------------- |
| Pending         | 已创建，等待手动修改 |
| PriceChanging   | 正在修改价格         |
| PriceChanged    | 全部 SKU 修改成功    |
| Restoring       | 正在恢复价格         |
| Completed       | 全部已恢复           |
| PartiallyFailed | 部分 SKU 执行失败    |
| Failed          | 全部 SKU 执行失败    |
| Cancelled       | 已取消，兼容历史数据 |

SKU 状态：

| 状态    | 说明                 |
| ------- | -------------------- |
| Pending | 待处理               |
| Success | 成功                 |
| Failed  | 失败                 |
| Skipped | 已跳过，兼容历史数据 |

## 5. 执行逻辑

### 5.1 修改价格

用户在列表点击“修改价格”后：

1. 校验任务属于当前店铺。
2. 读取任务 SKU 明细。
3. 跳过已经修改成功的 SKU。
4. 调用 Shopify Admin GraphQL `productVariantsBulkUpdate`。
5. 对每个变体设置 `price = targetPrice`，`compareAtPrice = originalPrice`。
6. 记录每个 SKU 的成功或失败状态。
7. 汇总更新任务状态和成功/失败数量。

### 5.2 恢复价格

用户在列表点击“恢复价格”后：

1. 校验任务属于当前店铺。
2. 只处理已经修改成功的 SKU。
3. 调用 Shopify Admin GraphQL `productVariantsBulkUpdate`。
4. 对每个变体设置 `price = originalPrice`，`compareAtPrice = null`。
5. 记录每个 SKU 的恢复结果。
6. 汇总更新任务状态和成功/失败数量。

## 6. 部署说明

该功能不依赖 Vercel Cron，也不需要后台轮询进程。部署 Shopify App 后，商家通过页面按钮触发修改和恢复操作。
